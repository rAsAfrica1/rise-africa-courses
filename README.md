## 🎯 Course Structure

Each course has 6 complete modules:

| Module | Focus | What You'll Learn |
|--------|-------|-------------------|
| **1** | Introduction & Basics | Species, benefits, African context, why this matters |
| **2** | Housing/Equipment | Facility design, construction, setup costs |
| **3** | Nutrition/Forage | Feeding strategies, cost optimization, sustainability |
| **4** | Health & Disease | Prevention, treatment, biosecurity protocols |
| **5** | Breeding/Management | Production cycles, expansion, quality improvement |
| **6** | Economics (CAPSTONE) | Complete business plan, 5-year projections, profitability |
