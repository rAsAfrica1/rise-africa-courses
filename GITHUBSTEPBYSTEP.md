# PART 1: CREATE GITHUB ACCOUNT (5 MINUTES)

## Step 1.1: Go to GitHub.com

1. Open your web browser (Chrome, Firefox, Safari, Edge)
2. Go to: **https://www.github.com**
3. You should see the GitHub homepage

**What it looks like:**
```
┌─────────────────────────────────────────┐
│  GitHub                                 │
│  Where the world builds software        │
│                                         │
│  Sign up    Sign in    [Menu]          │
└─────────────────────────────────────────┘
```

---

## Step 1.2: Click "Sign Up"

1. Look for **"Sign up"** button (top right of page)
2. Click it
3. You'll see the sign-up form

---

## Step 1.3: Enter Your Email

1. In the **"Email address"** field, type your email
   - Example: `yourname@gmail.com`
2. Click **"Continue"**

---

## Step 1.4: Create Your Password

1. In the **"Password"** field, create a strong password
   - Must be at least 15 characters OR
   - At least 8 characters with numbers and lowercase letters
   - Example: `MyFarm2026Skills`
2. Click **"Continue"**

**Remember this password!** You'll need it to log in.

---

## Step 1.5: Choose Your GitHub Username

1. In the **"Enter a username"** field, type your username
   - This will appear in your platform URL
   - Example: `johnfarmkenya` → URL becomes `johnfarmkenya.github.io/rise-africa-courses/`
   - No spaces, use lowercase letters and hyphens
   - Suggestions:
     - `riseafrica`
     - `africa-skills`
     - `farm-training`
     - Your name: `john-mwangi`

2. Click **"Continue"**

---

## Step 1.6: Verify Your Email

1. GitHub sends a verification code to your email
2. Check your email inbox (or spam folder)
3. Look for email from `noreply@github.com`
4. Copy the **verification code** (6 digits)
5. Paste it into GitHub form
6. Click **"Verify"**

---

## Step 1.7: Personalize Your Experience (Optional)

GitHub asks a few questions:
- "How many team members will be using GitHub?" → Pick any option
- "What are you interested in?" → Pick any option

You can skip these questions.

---

## Step 1.8: Welcome to GitHub!

You now have a GitHub account! 🎉

**You should see:**
- Your GitHub dashboard
- Username in top right
- "+" icon in toolbar

---

# PART 2: CREATE YOUR REPOSITORY (5 MINUTES)

## Step 2.1: Click the "+" Icon

1. Look at the **top right** of GitHub page
2. Find the **"+"** icon (next to your profile icon)
3. Click it
4. Select **"New repository"**

**Visual:**
```
    [Username]  +  [Menu]
                 ↑
                Click this
```

---

## Step 2.2: Fill in Repository Details

You'll see a form with several fields. Fill them in:

### Repository Name
```
Field: Repository name *
Enter: rise-africa-courses

(This is the folder name for your platform)
```

### Description
```
Field: Description (optional)
Enter: Agricultural education platform for African farmers - 
       Pig, Poultry, Beekeeping courses

(This helps people understand what your repository is)
```

### Public or Private
```
Choose: PUBLIC (selected by default)

(This makes your platform visible to everyone - you want this!)
```

### Initialize Repository
```
☐ Add a README file (UNCHECK THIS - we already have a README)
☐ Add .gitignore (leave unchecked)
☐ Choose a license (leave unchecked)
```

---

## Step 2.3: Create the Repository

1. Scroll to the bottom of the form
2. Click the **green "Create repository"** button
3. Wait a few seconds...

You'll now see your empty repository page.

**What you see:**
```
📦 rise-africa-courses
│
├─ You don't have any commits here yet
├─ Start your project with a README or add files
│
└─ Add files button
```

# PART 4: ENABLE GITHUB PAGES (5 MINUTES)

## Step 4.1: Go to Repository Settings

1. In your repository, look at the top tabs:
   ```
   Code | Issues | Pull requests | Settings | ...
   ```
2. Click **"Settings"** (far right)
3. Wait for settings page to load

---

## Step 4.2: Find Pages Section

Left sidebar menu appears:
```
⚙️ General
  📋 Code and automation
    └─ Actions
    └─ Webhooks
  🔒 Security
    └─ Deploy keys
  📜 Code, planning, and automation
    └─ Pages ← CLICK THIS
    └─ Environments
    └─ Rulesets
```

1. Click **"Pages"** in left sidebar
2. You're now in GitHub Pages settings

---

## Step 4.3: Configure Build and Deployment

You'll see a section called "Build and deployment":

```
┌────────────────────────────────────────┐
│ Build and deployment                   │
│                                        │
│ Source                                 │
│ ○ Deploy from a branch ← SELECT THIS   │
│ ○ GitHub Actions                       │
│                                        │
│ Branch                                 │
│ [main ▼]  [/ (root) ▼]                │
│            ↑              ↑            │
│         Branch          Folder        │
└────────────────────────────────────────┘
```

**What to do:**
1. Select **"Deploy from a branch"** (click the radio button)
2. In Branch dropdown: Select **"main"** (or "master" if that's what shows)
3. In Folder dropdown: Select **"/ (root)"** (should be default)
4. **DO NOT CHANGE** anything else

---

## Step 4.4: Save Settings

1. Look for **"Save"** button at bottom
2. Click it
3. Page will refresh

---

## Step 4.5: GitHub Pages Building

GitHub is now building your website!

You'll see a message:
```
Your site is ready to be published at 
https://YOUR_USERNAME.github.io/rise-africa-courses/

[Your site will be available shortly]
```

**Wait 1-2 minutes** for the website to build.

You'll see a yellow/orange notification that changes to green when ready:
```
✓ Your site is published at 
  https://YOUR_USERNAME.github.io/rise-africa-courses/
```

## ❓ Frequently Asked Questions

### Q: Can I edit the courses after deploying?
**A:** Yes! Edit the HTML file in GitHub, commit, and your site updates in 1-2 minutes.

### Q: What if a video link breaks?
**A:** Videos come from YouTube. If a video is removed, you can replace the YouTube link.

### Q: Can students download the courses?
**A:** They can save web pages locally. In future, you could add a download feature.

### Q: How many students can access?
**A:** Unlimited! GitHub Pages handles massive traffic for free.

### Q: Can I add more courses?
**A:** Yes! Upload new HTML files anytime using the same process.

### Q: What if I need a custom domain?
**A:** Optional. Register a domain (~$10/year) and configure in GitHub Settings → Pages.

### Q: How do I make money from this?
**A:** Options: Donations, premium features, sponsorships, partnerships with agricultural companies.

## 📞 Support

If something doesn't work:

1. **Check GITHUB-DEPLOYMENT.md** for more detail
2. **Check browser console**: Press F12, look for error messages
3. **Try different browser**: Chrome, Firefox, Safari
4. **Clear cache**: Ctrl+Shift+Delete (or Cmd+Shift+Delete on Mac)
5. **Wait and refresh**: Sometimes GitHub Pages takes 1-2 minutes to update
